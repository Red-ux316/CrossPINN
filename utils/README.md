# Utils & Diagnostics Directory

This directory contains logging and diagnostic utilities for the **CrossPINN** framework.

## Core Modules (`CrossPINN/utils/`)

- `logger.py`: Provides colorful terminal logging functions (`print_info`, `print_success`, `print_error`, `Colors`).
- `loss_landscape.py`: Analysis script for 1D loss landscape interpolation between initial and final model weights.
